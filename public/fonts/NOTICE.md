# Bundled fonts

X-Facture bundles the following font files unmodified from their official upstream repositories:

- **Inter Variable** — https://github.com/rsms/inter — licensed under the SIL Open Font License 1.1. See `LICENSE-INTER.txt`.
- **JetBrains Mono Variable** — https://github.com/JetBrains/JetBrainsMono — licensed under the SIL Open Font License 1.1. See `LICENSE-JETBRAINS-MONO.txt`.

- **Material Icons** — https://github.com/google/material-design-icons (via the `material-icons` npm package, `iconfont/material-icons.woff2`) — licensed under the Apache License 2.0. See `LICENSE-MATERIAL-ICONS.txt`.

The fonts are self-hosted so invoice previews and PDF generation do not depend on Google Fonts being reachable.
