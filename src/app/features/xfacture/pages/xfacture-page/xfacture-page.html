Turn your invoice into structured business data.

x-facture keeps your invoice data local and gives you both browser-side XML exports and an optional server-side Factur-X PDF/A workflow through the X-Facture API.

API

Reusable X-Facture services

The same API also provides invoice calculations, exchange rates and QR generation for x-facture and future X-Facture products.

How the API fits into x-facture

  1. Your invoice remains the source of truth in x-facture and can continue to work locally.
  2. CII and UBL XML can be generated in the browser without sending the invoice to a server.
  3. Factur-X PDF/A generation is delegated to the dedicated X-Facture API when requested.
  4. The API is reusable, so QR generation, currency data and future document services can share the same infrastructure.

API-backed features require an internet connection. Structured XML export remains available locally. Legal compliance and electronic-invoicing network requirements still depend on the applicable country and profile.
